## 一、这块板练的是什么

| 环节 | 具体做了什么 |
|---|---|
| 抄板方法论 | 先抄**实物丝印**（R1~R19、电容 `104`/`106` 三位码），再对照 TI 原理图认出「哪几颗决定参数、哪几颗是 0 Ω 配置」 |
| 看懂"万能板" | 19 个电阻里相当一部分是 **0 Ω 跳线**：几种接法（反相/同相、IN_1 还是 IN_2、要不要偏置）全部布好线，**焊哪几颗生效哪条路** |
| 原理图 | 立创商城元件库（按 C 号搜索）、符号引脚实测核对（OPA690：2=IN−、3=IN+、6=OUT、7=+VS、4=−VS、8=DIS、1/5=NC） |
| PCB 布局 | 4 个 SMA **贴边**（焊盘伸出板框）、U1 居中、**反馈网络 RG/RF 最短化**、去耦紧贴电源脚 |
| 布线 | 线宽分级实测：**信号 10 mil ×56 段 / ±5 V 20 mil ×40 段 / GND 30 mil ×51 段** |
| 铺铜 | **底层大面积 GND 铺铜**，SMA 地脚打过孔接铺铜 |
| 出图 | 嘉立创EDA `导出 → PCB 制板文件`，一次导出 14 个文件（含钻孔与飞针测试） |

## 二、电路与指标

```
IN(SMA) ─RM 67Ω─┬─ RG 200Ω ─●─ IN−(2)          反相端
                │           │
               GND          RF 402Ω
                            │
                          OUT(6) ─ RO 50Ω ─ OUT(SMA)
IN+(3) ─ RB 146Ω ─ GND
+5 V → 7 脚，−5 V → 4 脚，DIS(8 脚) → 跳线排针（悬空 = 使能）
```

| 项 | 值 |
|---|---|
| 运放 | **OPA690IDG4**（SOIC-8，立创 C1348107）—— 电流反馈型高速运放 |
| 增益 | 反相：G = −RF/RG = −402/200 ≈ **−2** |
| 输入匹配 | RM 67 Ω ∥ RG 200 Ω = **50.2 Ω** ≈ 50 Ω（67 这个值的来历） |
| 偏置补偿 | RB 146 Ω（= RG + 50∥67 与 RF 的直流平衡） |
| 输出背匹配 | RO 50 Ω → 接 50 Ω 负载时整机 50 Ω 入 / 50 Ω 出、增益 ≈ −1 |
| 电源 | ±5 V（XH2.54-4P 输入：−5 V / GND / +5 V / 空），0.1 µF + 10 µF 去耦 |
| 接口 | 4 × SMA（IN_1 / IN_2 / OUT_1 / OUT_2）+ 4 × 3P 排针（DIS 跳线 / 扩展） |
| 机械 | 4 × M2.5 安装孔（配 M2.5×11 六角铜柱） |

## 三、交付文件核验（实测数据）

嘉立创EDA 一键导出 **14 个文件**：9 个 Gerber + 2 个钻孔 + 飞针测试 + 下单必读。

| 核验项 | 实测 |
|---|---|
| 单位 / 格式 | 全部 `%FSLAX45Y45*%` + `%MOMM*%`（mm，4 位整数 5 位小数） |
| 板框 | 未落 GKO 的矩形描边：**48.260 × 38.100 mm**，器件全在框内 |
| 顶层铜箔 | 96 个区域填充 + 909 段走线 + **117 个焊盘** |
| 底层铜箔 | 47 个区域填充 + 2111 段走线 + 59 个焊盘（**大面积 GND 铺铜**） |
| 丝印 | 顶层 863 段（位号 + 接口标注），底层极简 |
| 阻焊 | 顶层开窗 98 个 / 底层 40 个 |
| 钻孔 | **59 孔，5 种刀**：Ø0.305 ×19（过孔）、Ø1.100 ×16（SMA 地脚）、Ø1.300 ×4、Ø1.600 ×16（排针/XH）、Ø2.500 ×4（M2.5 安装孔） |
| 钻孔格式 | `M48` + `METRIC` + 显式小数点，另有独立的过孔刀表（19 孔） |
| DRC | 出图前 87 条 → **3 条**（`PCB and schematic netlist does not match`）|

> **关于那 3 条 DRC**：根因在原理图侧 —— 有 4 个"试放后丢在角落的单脚符号"（U1/U3/U4/U5），PCB 里没有它们。
> **这属于工程记录不一致，不影响 Gerber 与制造**（PCB 数据本身是完好的）；要让 DRC 彻底归零，在原理图里删掉这 4 个符号即可。

## English Abstract

A dual-supply (**±5 V**) inverting amplifier module built around the **TI OPA690** current-feedback op-amp
(50 Ω in / 50 Ω out, G ≈ −2 with RM 67 Ω / RG 200 Ω / RF 402 Ω / RB 146 Ω / RO 50 Ω),
designed in **EasyEDA Pro** (JLCPCB's free EDA) — a redraw of a real board with 4 SMA connectors,
4 × M2.5 mounting holes and a 19-resistor "configurable-by-0 Ω-jumper" network, on a 48.26 × 38.10 mm 2-layer
stack with a large bottom-layer ground pour. Delivered as a 14-file manufacturing package
(9 Gerbers + 2 drill files + flying-probe data), with all geometry verified against the Gerber data.
