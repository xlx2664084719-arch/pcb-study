## 项目一 ★ Butterworth 低通滤波器（双层版 + 四层版）

[![四层版顶层](Butterworth低通滤波器/图片/四层-顶层装配视图.png)](Butterworth低通滤波器/README.md)

**同一块板画两遍**：先双层，再改成四层（SIG / GND / PWR / SIG），用来吃透"参考平面"这件事。

| | 双层版 | 四层版 |
|---|---|---|
| 叠层 | Top / 介质 / Bottom | **L1 SIG · L2 GND · L3 PWR · L4 SIG**（嘉立创 `JLC04161H-7628`） |
| 内电层 | — | L2 整片地 + L3 电源平面（**+5 V 片上分割出 −5 V 孤岛**） |
| 过孔 | 53 | 72（**19 个 GND 缝合孔**把表层地缝到地平面） |
| 尺寸 / 板厚 | 48.260 × 38.100 mm / 1.6 mm | 同左 |
| DRC | **0 违规** | **0 违规** |
| Gerber | 8 个文件 | **10 个文件**（含 `GP1`/`GP2` 两个负片内电层） |

**电路**：±5 V 双通道 Sallen-Key 低通，OPA2140 精密双运放 ×2（4 个运放单元全用上），SMA 输入输出 ×4，全部按立创商城料号选型。

**交付前逐项核验过的内容**：板框实测 48.260 × 38.100 mm、单位格式统一 `%FSLAX44Y44*%`/`%MOMM*%`、
内电层闪光数 = 钻孔数 = 72、钻孔文件 `M48`+`METRIC`+`TZ`+4:4、与双层版逐孔对比（原 53 孔字节级一致）。

## 项目二 · OPA_U 运放模块（双层 · **嘉立创EDA 绘制**）

| 顶层 | 底层（大面积 GND 铺铜） |
|---|---|
| [![顶层](OPA运放板/图片/OPA-03-顶层装配视图.png)](OPA运放板/README.md) | [![底层](OPA运放板/图片/OPA-04-底层装配视图.png)](OPA运放板/README.md) |

**TI OPA690 高速运放**的反相放大模块（50 Ω 入 / 50 Ω 出、G ≈ −2），照实物抄板：
4 个 SMA 贴边、19 个电阻（含 **0 Ω 配置跳线**的"万能板"思路）、四角 M2.5 安装孔、底层大面积 GND 铺铜，
48.26 × 38.10 mm 双层。**用嘉立创EDA专业版从原理图画到出 Gerber**，与滤波器板（AD）形成工具对照。

## 技能清单

| 环节 | 会做什么 |
|---|---|
| 原理图 | 自建符号库 / 封装库，从立创商城导入元件并沉淀成通用库；网络标签、电源端口、编译查错 |
| 抄板 | 抄实物丝印（R1~R19、电容 104/106 三位码）→ 对照原厂原理图区分"决定参数的件"与"0 Ω 配置件" → 只画通一种配置 |
| PCB 布局 | 接口靠边、信号流向、**差分对严格对称**、按模块分区；**反馈环路面积最小**；原点法做对称布局 |
| 布线 | 45° 走线、推挤模式、换层打过孔、**线宽分级**（信号 10 mil / 电源 20 mil / 地 30 mil） |
| 铺铜 / 平面 | 铺铜指定网络、**四层叠层设计**、**内电层负片**、**平面分割（Split Plane）**、**缝合孔（Via Stitching）** |
| 规则与检查 | 设计规则（间距/线宽/过孔/平面间隙）配置、DRC 归零、`Shift+S` 单层目视核对、网表逐脚复核 |
| 出图与制造 | Gerber 各层选择、NC Drill 单位格式一致、`.GM` 扩展名坑、嘉立创下单参数核对、**Gerber 逐文件内容核验**（板框尺寸 / 单位格式 / 闪光数=孔数 / 逐孔对比） |
| 工具 | **Altium Designer 25**（叠层 / 内电层 / 负片 / 规则）+ **嘉立创EDA 专业版**（免费，一键下单）+ 立创商城选型 + Git |
